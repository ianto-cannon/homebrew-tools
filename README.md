# Homebrew Tools

A collection of small command-line utilities by [Ianto Cannon](https://ianto-cannon.github.io/).

## Installation

Install individual utilities directly with Homebrew:

```bash
brew install ianto-cannon/tools/trash
brew install ianto-cannon/tools/clean-clipboard
brew install ianto-cannon/tools/make-sitemap
brew install ianto-cannon/tools/coffee
brew install ianto-cannon/tools/cake
brew install ianto-cannon/tools/owl
```

Alternatively, add the tap first:

```bash
brew tap ianto-cannon/tools
```

Then install utilities by name:

```bash
brew install trash
```

## Utilities

| Utility | Description |
|---|---|
| `trash` | Move files to the macOS Trash using Finder |
| `clean-clipboard` | Mask emails and phone numbers from clipboard text |
| `make-sitemap` | Generate a website sitemap |
| `coffee` | Print ASCII coffee |
| `cake` | Print ASCII cake |
| `owl` | Print ASCII owl |

## Requirements

- macOS
- [Homebrew](https://brew.sh/)

## Updating

```bash
brew update
brew upgrade
```

## Uninstalling

```bash
brew uninstall trash
```

Replace `trash` with the utility you want to uninstall.
